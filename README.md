Что было добавлено:
1. Валидация полей
При вводе проверяется, что оба поля заполнены

Если поле пустое, оно подсвечивается красной рамкой

Кнопка "Написать" блокируется, пока оба поля не заполнены

Выводится сообщение об ошибке

2. Добавление комментария
При клике на кнопку создается новый комментарий

Используется шаблон на основе существующих комментариев

Подставляются имя и текст из полей ввода

3. Дата и время
Используется объект Date для получения текущей даты

Формат: DD.MM.YY HH:MM (как в существующих комментариях)

4. Лайки
Новые комментарии появляются с 0 лайков

Работает клик по лайку для увеличения счетчика

5. Удобство использования
Автофокус на поле имени после добавления

Нажатие Enter в поле имени переключает на поле текста

Ctrl+Enter в поле текста отправляет комментарий.

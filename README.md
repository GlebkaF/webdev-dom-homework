Домашнее задание №2: События на динамических элементах
Что было изменено и добавлено:
Рефакторинг хранения данных 📦

Создан массив commentsData для хранения всех комментариев

Каждый комментарий теперь содержит объект с полями:

javascript
{
  id: number,        // Уникальный идентификатор
  name: string,      // Имя автора
  date: string,      // Дата создания
  text: string,      // Текст комментария
  likes: number,     // Количество лайков
  isLiked: boolean   // Состояние лайка (лайкнут или нет)
}
Комментарии больше не хранятся только в HTML-разметке

Реализована рендер-функция 🔄

Создана функция renderComments(), которая полностью отрисовывает список из массива данных

При любом изменении данных вызывается перерисовка всего списка

Единый источник истины - массив данных

Управление лайками через булево значение ❤️

Вместо прямого изменения DOM, теперь изменяются данные в массиве

Добавлено свойство isLiked для отслеживания состояния лайка

Реализованы оба сценария:

✅ Поставить лайк: пустое сердечко → закрашенное, счетчик +1

✅ Убрать лайк: закрашенное сердечко → пустое, счетчик -1

Управление классом активности 🎨

❌ НЕ используется classList.add() и classList.remove()

✅ Используется булево значение isLiked для установки класса через className:

javascript
if (comment.isLiked) {
  likeButton.className = 'like-button active';
} else {
  likeButton.className = 'like-button';
}
Делегирование событий 🎯

Один обработчик на весь список комментариев вместо множества обработчиков

Использован e.target.closest() для поиска кнопки лайка

Работает для всех комментариев, включая новые

Поиск комментария по data-id атрибуту

Изменения в добавлении комментариев ➕

Новый комментарий добавляется в массив commentsData

После добавления вызывается renderComments() для обновления списка

Новые комментарии имеют likes: 0 и isLiked: false
